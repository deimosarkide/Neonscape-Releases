# Neonscape — Android Releases

Public, binary-only release channel for the Neonscape Android app. The application source and development repository remain private.

## Download

Approved signed APKs and release notes will appear on the [Releases page](https://github.com/deimosarkide/Neonscape-Releases/releases). No release has been published yet.

Android requires the same signing certificate for an in-place update. Do not uninstall an existing app without first considering its locally stored data.

This repository contains release metadata and downloadable binaries only, not the application source code.
